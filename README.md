# Halving Labs

**Bitcoin for real businesses.** We help shops and companies in Italy use Bitcoin: payments, treasury, self-custody and mining. We also build free, open tools for the community.

🇮🇹 Italy · ⚡ Lightning · 🟠 Bitcoin only

## Projects

### 🗡️ [Proof of Quest](https://poq.halvinglabs.it)
A retro action RPG where **every Bitcoin block is a dungeon**: hash, transactions, fees and mining pool shape each level. Free in the browser, no account needed.
The engine is open source: [proof-of-quest-engine](https://github.com/HalvingLabsITA/proof-of-quest-engine) (MIT).

### 📊 [Bitcoin Stats bot](https://github.com/HalvingLabsITA/bitcoin-stats-bot)
Telegram bot and web dashboard: price, fees, blocks, difficulty, whale alerts and halving countdown, powered by mempool.space.
Live channel: [t.me/hlbitcoinstats](https://t.me/hlbitcoinstats)

## What we do
- Bitcoin and Lightning payments for shops, with BTCPay Server
- Corporate treasury and self-custody
- Home mining optimization
- Meetups and Bitcoin education in Italy
